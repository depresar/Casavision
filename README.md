# CASAVISION — сайт (макет v1)

Статичный HTML-макет сайта креативного ателье CASAVISION (Дубай). Главный референс — abvstk.com (сетка, иерархия, подача кейсов), заблюренный логотип — accentjwlry.ru.

## Структура
- `index.html` — главная (EN), `ru/` — русская версия всех страниц. Переключатель EN / RU в шапке и меню.
- `fragments-de-paris.html`, `the-hold.html`, `confesso-milano.html`, `velvet-meadow.html`, `sliceit.html`, `sensorial-dive.html` — страницы проектов: бриф → идея → слова концепции → мудборд (собирается при скролле) → визуализации → результат → CTA → следующий проект.
- `assets/css/site.css`, `assets/js/site.js` — общие стили и поведение (без библиотек).
- `assets/img/<проект>/` — картинки из портфолио (очищены от артефактов и увеличены; для финала нужны оригиналы).
- `assets/video/hero.mp4` (1080p) и `hero-720.mp4` (телефоны) — фоновое видео, очищено от шума и увеличено.
- `assets/brand/logo-*.svg` — логотип в векторе (встроен в CSS).
- `tools/build.py` — генератор всех страниц: тексты и данные проектов лежат там.

## Сборка
```
python3 tools/build.py
```
